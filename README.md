# IANO PTCG Bracket Builder

純前端（HTML / CSS / JavaScript）單頁應用，用來產生寶可夢卡牌（PTCG）活動的**單淘汰賽**樹狀對戰表。採用經典**左右對開**布局：左側為種子 1 半區、右側為種子 2 半區，決賽與冠軍在中央。無需建置，直接開啟 `index.html` 即可。

## 功能

- 選擇 **8強 / 16強 / 32強**
- **種子自動編號**：選手列依 #1～#N 排列，使用者不必手動填種子
- 可填欄位：**選手名稱**、**玩家ID**、**使用牌組**
- 系統依標準種子排序把選手放到對戰表（#1 與 #2 只會在決賽相遇）
- 左右對開樹狀圖，兩側皆有連接線（右側為鏡像）
- 後續輪次顯示「勝者晉級」；每場有 **晉級**／**清除**（改選或清除會連帶清掉後續依賴）
- 列印友善（橫向、依規模縮放、隱藏控制列）
- `localStorage` 自動儲存（新版資料格式；舊版資料會安全略過）
- 極簡白／淺灰介面，紅色點綴

## 對戰表布局

```
[左側半區：種子1…]     [決賽]     [右側半區：種子2…]
  32/16/8強 → … → 準決賽   ↕   準決賽 ← … ← 32/16/8強
                         [冠軍]
```

- **8強**：左 1v8、4v5；右 2v7、3v6
- **16強**：左 1v16、8v9、4v13、5v12；右 2v15、7v10、3v14、6v11
- **32強**：同標準 bracket，左含 #1，右含 #2

## 使用方式

1. 選擇賽事規模。
2. 在選手資料區依種子列填寫名稱、玩家ID、牌組。
3. 按「產生對戰表」。
4. 比賽中點勝方旁的 **晉級**；可再點「已晉級」取消，或用該場 **清除**。
5. 「列印」產出紙本；「重置全部」清空資料。
