# IANO PTCG Bracket Builder

純前端（HTML / CSS / JavaScript）單頁應用，用來產生寶可夢卡牌（PTCG）活動的**單淘汰賽**樹狀對戰表。無需建置工具，直接開啟 `index.html` 即可使用。

## 功能

- 選擇 **8強 / 16強 / 32強**
- 每個第一輪位置可填寫：**選手ID**、**編號（種子）**、**使用牌組**
- 一鍵依標準種子排序自動填入編號
- 產生清楚的樹狀對戰表（含連接線、輪次標籤：32強 → 16強 → 8強 → 準決賽 → 決賽 → 冠軍）
- 後續輪次預設顯示「勝者晉級」占位
- **晉級按鈕**：每場比賽每位選手旁有「晉級」，點擊後填入下一輪對應位置，一路到決賽與冠軍
- 每場有「清除」可取消該場晉級並自動清除依賴它的後續結果；可重新選擇晉級對象
- 全域「重置全部」清空資料
- 瀏覽器 `localStorage` 自動儲存
- 列印友善（橫向、隱藏控制列、保留顏色）
- 極簡白／淺灰介面，紅色作為點綴，響應式設計（小螢幕可橫向捲動對戰表）

## 使用方式

1. 選擇賽事規模（8 / 16 / 32）。
2. 在「第一輪選手資料」填入選手ID、種子編號、牌組（可按「自動填入種子編號」）。
3. 按「產生對戰表」。
4. 比賽進行時，在對戰場次中點選勝方旁的 **「晉級」**：
   - 該選手會出現在下一輪對應的「勝者晉級」位置。
   - 若再點同一位（顯示為「已晉級」），會取消晉級並清除後續依賴結果。
   - 若改點另一位，會改為新勝方並清除舊勝方造成的後續結果。
   - 每場下方的 **「清除」** 只清該場與後續，不影響其他無關場次。
5. 需要紙本時按「列印」。
6. 「重置全部」會清空所有選手與晉級資料。

## 部署到 GitHub Pages

1. 確認本 repo 的 `main` 分支已包含上述四個檔案。
2. 到 GitHub：**Settings → Pages**。
3. **Source** 選 **Deploy from a branch**。
4. Branch 選 `main`，資料夾選 `/ (root)`，儲存。
5. 稍候即可透過  
   `https://ianohuang.github.io/pokemon-knockout-bracket/`  
   開啟。

也可直接用瀏覽器開啟本機的 `index.html`，無需伺服器。
